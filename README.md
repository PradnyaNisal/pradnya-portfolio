# Pradnya Nisal — Cloud & DevOps Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize before publishing
- Verify all project descriptions and repository links.
- Replace the LinkedIn placeholder URL with your actual profile URL.
- Add your resume PDF only when it is ready.
- Add project screenshots after the projects are completed and documented.

## Publish with GitHub Pages
1. Push these files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` (or your default branch) and `/ (root)`.
5. Save and wait for the published site URL.

This portfolio is a learning and project showcase. Keep experience and project claims accurate.
